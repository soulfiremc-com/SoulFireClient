# Provider logos

These logos identify third-party provider integrations and shop links. Each provider owns its logo and trademark.

Files come from `soulfiremc.com` commit `050d3c3174b3b86bbb14c242c466b3df24708941`, in `public/providers` and `public/accounts`.
The geometry and colors are unchanged. These files were resized to 128 px WebP to reduce bundle size:
`proxyseller`, `flashproxy`, `altsfast`, `kynoselling`, `localts`, and `fernan`.
`ravealts.webp` is the first frame of the animated `ravealts.gif`.

Replace a logo with the provider's current official artwork when its branding changes.
