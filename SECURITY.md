# SoulFireClient security policy

Do not open a public issue or pull request for a vulnerability.
Email [security@soulfiremc.com](mailto:security@soulfiremc.com) or privately message `pistonmaster` through the [SoulFire community](https://soulfiremc.com/discord).

Include the client version, connected server version, OS, architecture, and installation method.
Describe reproduction steps, expected and actual behavior, potential impact, and required permissions.
For Electron reports, identify whether the issue affects the main process, preload, renderer, updater, or integrated server.
Remove tokens, credentials, account data, and proxy keys from logs and examples.
Use an isolated environment and systems that you own or have permission to test.

Follow the [organization security policy](https://github.com/soulfiremc-com/.github/blob/main/SECURITY.md) for private handling and coordinated disclosure.
Include affected older releases or development builds as well as current releases.
This policy does not establish a fixed response deadline or backport schedule.

For ordinary client bugs and usage questions, use [SUPPORT.md](SUPPORT.md).
